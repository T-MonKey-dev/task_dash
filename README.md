# Task Dash

A task management application built with React and TypeScript. The project focuses on building an interactive user interface and practicing core React concepts, including component-based development, state management, event handling, and immutable state updates.

## Features

- **Task creation:** Add new tasks using an input form.
- **Task completion:** Mark tasks as completed or pending.
- **Dynamic task list:** Render tasks from application state and update the interface in response to user interactions.
- **Input validation:** Prevent empty or whitespace-only task titles from being submitted.

## Tech Stack

- React
- TypeScript
- Vite
- HTML and CSS

## Getting Started

### Prerequisites

- Node.js
- pnpm

### Installation

Clone the repository and navigate to the project directory:

```bash
git clone <your-repository-url>
cd task-dashboard
```

Install the dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open the local URL displayed in your terminal to view the application.
